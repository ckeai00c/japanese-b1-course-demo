# 日语 B1 词组关模板

这是从旧“个性化-词组关”中拆出的独立词组关模板。Word 文档只提供语料，界面与交互由本模板固定。

## 固定流程

每课必须有 3 个核心项，词组关固定为 15 步：

1. 单词 1：核心词图片、曝光句、2 选 1 词义题
2. 搭配 1-1 拼 Chunk
3. 搭配 1-2 拼 Chunk
4. 单词 2：核心词图片、曝光句、2 选 1 词义题
5. 搭配 2-1 拼 Chunk
6. 搭配 2-2 拼 Chunk
7. 单词 3：核心词图片、曝光句、2 选 1 词义题
8. 搭配 3-1 拼 Chunk
9. 搭配 3-2 拼 Chunk
10. 句子 1：代入搭配 1-1 的写句子题
11. 句子 2：代入搭配 2-1 的写句子题
12. 句子 3：代入搭配 3-1 的写句子题
13. 句子 4：代入搭配 1-2 的口语翻译题
14. 句子 5：代入搭配 2-2 的口语翻译题
15. 句子 6：代入搭配 3-2 的口语翻译题

词组或句子拼完后，选项区消失并展示一条完整日文内容；中文只在点击查词时出现。核心词、曝光句、Chunk、完整词组和句子都使用 Minami 机器音；若音频文件缺失，引擎会使用浏览器日语 TTS 兜底。点击后界面立即标记结果并播放音频，下一次人为点击可以打断上一段音频。日文 Chunk、中文提示、对话和完整句子都支持中日双语查词。口语题使用浏览器语音识别判断结果，不保存录音；点击“现在不做口语题”后，当前及后续口语题统一改为句子 Chunk 题，且不自动播放句子音频。

## 换课方式

只编辑 `course.config.js` 中的 `lessons`。每个核心项必须包含：

- `core` / `reading` / `meaning` / `distractors`
- `coreImage`
- `collocation1`
- `exposure`
- `collocation2`
- `written`
- `oral`

每个搭配至少拆成 2 个 Chunk，标点写在 Chunk 文本末尾即可，渲染时会自动固定在横线外。
`written.lookupSegments` 单独定义中文题干的查词分段，每段包含 `zh` 与对应的 `jp`，所有 `zh` 必须完整拼回原中文题干；这样作答 Chunk 的语法说明不会污染题干。`dialogue.reading` 用于会话注音，会话音频优先读取音频映射，缺失时使用日语 TTS。
`sceneImage` 使用无人场景底图，NPC 独立叠加。对话气泡按说话顺序自动横向切换。V3 音效按文件名绑定：`audio_combo*` 连续答对、`correctSpeak` 口语正确、`PopUpOpen` 查词弹出、`GameSucceed` 通关；`showCoin` 与 `only_get_coin` 预留给金币动画。

## 本地运行

```bash
npm run validate
npm run serve
```

访问 `http://127.0.0.1:4175/`。局域网分享时使用本机局域网 IP 加端口 `4175`。

也可以从工作区根目录启动局域网分享：

```bash
DEMO_DIR="$PWD/phrase-course-template" PORT=4175 ./serve-lan-demo.sh
```

把终端输出的局域网地址发给同一网络中的设备即可；电脑保持运行命令即可持续提供页面。

## GitHub Pages
